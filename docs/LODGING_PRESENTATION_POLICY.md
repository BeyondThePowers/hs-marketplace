# Marketplace lodging presentation policy

## Purpose

Lodging is decision-supporting information for a hunt. It is not a primary marketplace inventory category unless a property has enough verified, useful content to justify its own page.

## Accommodation modes

A hunt can publish either of these accommodation forms:

- `lodge`: a reference to a verified lodge entity published by the same outfitter source.
- `arranged`: a factual package-level description when the exact property is selected later, varies by date, or is not documented well enough to publish as an entity.

An arranged accommodation must not invent a property name, capacity, amenities, imagery, or other details. It should state only facts supported by the hunt package source.

## Public presentation

- Both modes appear in the hunt page's `Where you will stay` section.
- Lodge entities remain structured so they can be reused across hunts and updated once.
- Lodge entities do not receive a public marketplace route by default.
- A source must explicitly set `standalonePage: true` before a lodge route and link are generated.
- Marketplace discovery and search should remain centered on hunts, destinations, species, dates, price, and outfitters.

This keeps hunt pages complete without duplicating the full editorial role of an outfitter's own marketing site.
